directly before a real launch; this is a snapshot for quick reference while building.

## Typography

Roboto, free via Google Fonts. Weights: Thin, Light, Regular, Medium, Bold, Black (all with
italics). Use only 2–3 weights at a time for consistency and legibility.

## Logos

Not included in this repo — logo files require a CruzID and live behind UCSC's Google Drive.
Four systems exist depending on context:

- **Primary logo** — when the audience already knows UC Santa Cruz.
- **Horizontal lockup** — UCSC + Baskin Engineering paired, for audiences unfamiliar with UCSC.
- **Vertical lockup** — formal settings, can include department name.
- **Logomark** — symbol only, for casual use (merch, social).

Each comes in 4 color options (full-color, reversed white, black, white reversed). Minimum
size: 50px digital for primary/logomark, 70px digital for lockups.

**Don't**: stretch/distort, rotate (except 90° increments), recolor, change typeface, crop, add
drop shadows/strokes/effects.

Department logos exist for CSE, ECE, Applied Math, Biomolecular Engineering, Computational
Media, and Statistics, each in UCSC-paired and department-only versions.
